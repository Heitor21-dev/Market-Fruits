# 🍎 Market Fruits

Uma interface web interativa que simula uma banca de frutas de feira livre. O projeto permite que o usuário interaja visualmente com os produtos, podendo pegar as frutas da bancada, adicioná-las a um carrinho de compras ou devolvê-las ao seu lugar de origem.

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o intuito de praticar e consolidar conhecimentos fundamentais de desenvolvimento front-end, explorando estruturação semântica, estilização, posicionamento de elementos e interatividade na tela.

## ✨ Funcionalidades

- **Visualização da Banca:** Exibição organizada de diversas frutas frescas na bancada.
- **Pegar Frutas:** Seleção interativa dos itens disponíveis na banca.
- **Carrinho de Compras:** Adição das frutas escolhidas ao carrinho.
- **Devolução:** Possibilidade de retirar itens do carrinho e devolvê-los para a banca.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação da banca, frutas e área do carrinho.
- **CSS3:** Estilização visual, cores, layout e efeitos de interação.
